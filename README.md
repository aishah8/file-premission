File Permissions in Linux
Permissions in Linux systems control who can read, write, and execute files or directories. These permissions are divided into three main categories:  
1	User (Owner): The person who owns the file. 
•	Can have permissions to Read, Write, and Execute.
2.	Group: A set of users who share similar access rights.
•	Members of the group can also have permissions to Read, Write, and Execute.
3.	Others: Everyone else (not the owner or part of the group).
•	They can be granted permissions to Read, Write, or Execute as needed.
How to Assign File Permissions:
File permissions in Linux determine who can read, write, or execute a file. Permissions are managed using the chmod command
